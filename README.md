# event-calendar

Calendario virtual de eventos de tecnología de Málaga, con modo claro y oscuro y un toque geek.

Lo creé el 27 de octubre de 2026 en el taller de GitHub Copilot app de GitHub Dev Days Málaga, partiendo de una idea inicial y un primer prompt.

## Qué incluye

- Página "TechPulse Málaga" en español con calendario mensual y lista de próximos eventos.
- Cambio entre tema claro y oscuro, que se recuerda en el navegador.
- Eventos de Meetup Málaga organizados por categoría y mostrados en el calendario.

## Cómo abrirlo

Es un sitio estático compuesto por HTML, CSS y JavaScript. Descarga el repositorio y abre `index.html` en el navegador. No necesita instalar nada.

## Estructura

- `index.html`: página y contenido principal.
- `styles.css`: estilos, diseño responsive y temas claro/oscuro.
- `script.js`: eventos, filtros y lógica del calendario.

## Automatización

En el taller también se creó una automatización en GitHub Copilot app para sacar los eventos de Meetup Málaga y proponer un pull request a este repositorio.
